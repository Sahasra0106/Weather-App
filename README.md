# 🌦️ Weather App

A responsive Weather Application built using HTML, CSS, and JavaScript. It provides real-time weather information and a 5-day weather forecast for any searched city or the user's current location.

## 🚀 Live Demo

[View Weather App](https://sahasra0106.github.io/Weather-App/)

## ✨ Features

- Search weather by city name.
- Get current location weather using GPS.
- Display current temperature.
- Show weather conditions with icons.
- Display humidity and wind speed.
- 5-day weather forecast.
- Responsive design for mobile and desktop devices.
- Loading indicator while fetching weather data.

## 🛠️ Technologies Used

- HTML5 – Structure of the application.
- CSS3 – Styling and responsive design.
- JavaScript – Application logic and DOM manipulation.
- Fetch API – Fetching weather data.
- Async/Await – Handling asynchronous operations.
- Open-Meteo API – Weather data and geocoding.
- Geolocation API – Accessing the user's current coordinates.

## ⚙️ How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://sahasra0106.github.io/Weather-App/
   ```
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Search for a city or click the My Location button.

## 🌐 API Used

This project uses [Open-Meteo API](https://open-meteo.com/), which provides weather forecasts and geocoding data without requiring an API key.
